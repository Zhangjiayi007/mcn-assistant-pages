Privacy Policy

Effective date: September 30, 2026

MCN Assistant is a private operational application used by its owner and authorized collaborators. This policy explains how the application handles Google user data.

Google data accessed

After an authorized user grants consent, MCN Assistant may access Google Drive files, folders, file metadata, Google Sheets spreadsheets, and spreadsheet values that are used in the authorized media-publishing workspace.

How data is used

Google data is used only to organize authorized media, maintain publishing task sheets, project approved operational data, and synchronize publication status and links. Google user data is not used for advertising or user profiling.

Data sharing

MCN Assistant does not sell, rent, or share Google user data with advertisers or unrelated third parties. Data is available only to the application owner, authorized operational collaborators, and infrastructure providers required to run the application.

Storage, security, and retention

OAuth credentials are stored on access-controlled infrastructure and are not included in public source files. Operational data is retained only as needed for the workflow and its audit history. Reasonable technical and organizational safeguards are used to limit unauthorized access.

Your choices

An authorized user may revoke the application's Google access at any time from the Google Account permissions page. Revocation prevents future access but does not automatically delete operational records that were previously created with the user's authorization.

Contact

For privacy questions or deletion requests, contact the application administrator through the project owner’s GitHub profile.
