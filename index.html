MCN Assistant

MCN Assistant is a private workflow tool used by its owner and authorized collaborators to organize media in Google Drive, maintain publishing task data in Google Sheets, and synchronize operational records.

The application is not offered for public signup. It accesses Google data only after an authorized user grants permission and only for the operational purposes described above.
